Manual backup files are JSON and are not encrypted by the app. Restoring a backup may replace existing ledger data and related local backup sections; review the in-app confirmation carefully. Keep exported files private and retain your own safe copy.

You can permanently delete the cloud account and synced records from Profile → Cloud Backup → Delete cloud account, or use the external instructions at https://keshab1997.github.io/khoroch-diary/account-deletion.html. This leaves the local ledger on the device; exported backup files must be deleted separately.
